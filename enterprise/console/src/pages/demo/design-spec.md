# 演示大屏设计规范（ACR-001 / ACR-002 的视觉真相源）

> 适用范围：**只有演示大屏**（`enterprise/console/src/pages/demo/`）。运营页面继续执行 M3-01 的
> 「后台是工具，信息密度优先」方针，本规范的任何 token 不得外溢到运营页。
> 架构 §2.3「Web 端不使用 HUD 主题」仍然成立——本规范不是 HUD 主题，是大屏专属的展示层规范。

## 设计原则（改样式前先读）

1. **动效只表达真实事件。** 粒子只在这一轮真正走过的边上流动；数字只在真实数据变化时滚动。
   给没走的边加粒子、给不变的数加动画，与拿模拟数据冒充真实是同一类不实表述。
2. **三层结构，各自独立降级。** 背景 shader（氛围）→ 中景链路图（叙事）→ 前景 KPI（数据）。
   任何一层失效，其余两层照常，且失效要如实可见（沿用本页「取不到就不能说是真的」的既有原则）。
3. **fake 警示不可被视觉弱化。** 运行形态条与风险区的可读性优先级高于一切酷炫效果；
   背景层永远不得降低它们的对比度。
4. **尊重 `prefers-reduced-motion`**：命中时 shader 降为静态渐变、粒子与呼吸停、数字直切。

## Token（落在 styles.css 的 `.demo` 作用域内，前缀 `--demo-`）

| Token | 值 | 用途 |
|---|---|---|
| `--demo-bg` | `#05060d` | 大屏底色（比控制台 `--bg` 更深一档，衬出发光） |
| `--demo-mesh-1..4` | `#0b1020` `#0969da` `#6e40c9` `#101828` | 背景 MeshGradient 四色——取自链路图的编排蓝 / 直连紫 / 深底，不引入新色相 |
| `--demo-glow` | `rgba(9,105,218,.45)` | 面板与节点辉光基色 |
| KPI 数字字号 | `clamp(40px, 6vw, 88px)` | 前景层主角；`font-variant-numeric: tabular-nums` 必开 |
| KPI 趋势色 | 沿用 `--ok` / `--warn` / `--err` | 大屏不新增第四种状态色（与 RunFlow 三色原则同源） |

## 动效参数（统一在此定，代码里不许出现别的魔法数）

| 动效 | 参数 | 说明 |
|---|---|---|
| 背景 shader | `speed 0.15`，暗色四色 | 低速氛围层，不许抢戏；WebGL 不可用 → 纯 CSS 径向渐变兜底 |
| 边粒子 | `dur 1.6s`，半径 4，颜色随边色 | 只出现在 walked 边；`repeatCount="indefinite"`；SMIL `animateMotion`，零依赖 |
| 当前节点呼吸 | `2.4s ease-in-out` 的 box-shadow 脉冲 | 只有 `▸ 此刻在这里` 的节点有 |
| KPI 数字滚动 | NumberFlow 默认时序 | 数据源与 10 秒刷新节奏不变 |

## 图层与 z-index

```
z 0  背景：MeshGradient canvas（sticky 视口高，pointer-events: none）＋ CSS 渐变兜底
z 1  内容：fake 警示（仅不全真实时出现）→ 现在流到哪了 → 最近 30 分钟 KPI
```

大屏只有这两个区块（2026-08-26 收敛），共享一个「当前会话」：流向图画谁、KPI 就圈到谁
（跟随实时 = 最近活动的会话；经会话弹窗可锁定任意有轨迹的会话）。
历史会话必须明标**「历史会话回放（非实时）」**——一张停着的图和"系统很闲"
在观众眼里没有区别。健康卡、四问表、审计表撤出大屏，各自的页面仍在，大屏不复述。

背景层**必须钉在视口高（sticky + 100vh），不许 absolute 铺满整节**：
铺满时 WebGL canvas 缓冲随页面内容变长（×dpr 实测到 2048×3562，≈29MB 显存逐帧全画），
钉视口高则恒为一屏——氛围层的开销必须是常数，不许跟着审计表的行数长。

投屏模式（fullscreen）固定为单一视口（single viewport），隐藏控制台 chrome，不产生页面翻页：
流程图弹性占用剩余高度，KPI 固定在底部信息带内；视口较矮时仅压缩辅助说明和卡片留白，
不删除流程图、会话切换、fake 警示或 KPI 数据。浏览器页面与大屏容器都禁止纵向溢出，
会话选择弹窗仍使用自身的局部滚动。

## 连线标签排版

- 标签位置使用流程图世界坐标（world coordinates）偏移，随缩放同比例移动，不按当前屏幕像素漂移。
- 工具名、并行工具和动作清单按 `/`、`‖` 等结构分隔符换行；已有换行与短标签保持原样。
- 工具层、权限门、应答汇聚和主链路旁路分别使用稳定语义通道（semantic lanes），通道顺序取图定义顺序，
  不依赖实时事件到达顺序。
- 标签背景保持不透明，标签避开节点包围盒；布局只改变展示位置，不改变边的端点、条件或并行语义。
